# Deep Learning & Neural Networks

## - ANN
- **Image (MNIST)**           >  Binary Classification Problem: Last Layers Contains 2 Neurons + Activation Function

- **Text (Reviews/Reuters)**  > Classification Problem: Multiclassification (1-46) > Last layers 46 + Activation Func (SoftMax)

- **Tabulars**                > Regression Problem: Last Layer Contains 1 Neuron + No Activation Function

- Uses Dense Layer Input : 1 Dimensional Input

- Functions: Relu - Softmax - Sigmoid
  
- ReLU (Rectified Linear Unit): Gives the input value if it is positive; otherwise, it gives 0.

- Softmax: Converts a set of numbers into probabilities that add up to 1. It is commonly used for multi-class classification.

- Sigmoid: Converts any number into a value between 0 and 1, often used for binary classification. Formula: σ(x) = 1 / (1 + e⁻ˣ)
